# Robot Learning, 2026

This repository is a personal working clone of the 2026 ETH Zurich Robot Learning course. It is not the official course repository.

- Course page: [cvg.ethz.ch/lectures/Robot-Learning](https://cvg.ethz.ch/lectures/Robot-Learning/)
- Upstream code: [mees-robot-learning-course/ethz-course-2026](https://github.com/mees-robot-learning-course/ethz-course-2026)

Each homework keeps its own instructions:

- [Homework 2: robot control and MDPs](hw2_robot_control_mdps/README.md)
- [Homework 3: imitation learning on the SO-100 arm](hw3_imitation_learning/README.md)
